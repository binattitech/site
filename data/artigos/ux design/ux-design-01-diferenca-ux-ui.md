# Diferença entre UX e UI: Explicação para Iniciantes

Nos estudos de programação, em algum momento surgem os termos UX design e UI design. Para muitos, é difícil diferenciá-los no começo, por causa dos nomes parecidos e da relação entre eles. Nessa postagem, você entenderá o que é UX e UI design e a diferença entre ambos.

---

## UX Design

UX Design significa *User Experience Design*, ou design de experiência do usuário em português. Seu principal objetivo é trazer uma boa experiência para o usuário, pensando na usabilidade e funcionalidade do site, aplicativo e outros produtos. O UX tem como principal função facilitar a vida do usuário, com foco em proporcionar uma ótima experiência do começo ao fim.

---

## UI Design

UI Design significa *User Interface Design*, ou design da interface do usuário em português. Seu principal objetivo é proporcionar ao usuário uma experiência agradável ao utilizar a interface, auxiliando-o a compreender e navegar pelo site ou aplicativo. O UI tem como função guiar o usuário pela interface e ajudá-lo a atingir seu objetivo sem dificuldades.

---

## Conclusão

De forma simples: o UI guia o usuário pela interface para que ele atinja seu objetivo, enquanto o UX proporciona uma boa experiência da entrada no site até a conclusão desse objetivo.
